# VR16 CPU
Updated based on: <a href="https://github.com/bsod2528/cpu/commit/a03ddea555b00e2594c6f16772c364bf0e9e9897">a03ddea555b00e2594c6f16772c364bf0e9e9897</a>
{:.info}

This is a simple 16-bit RISC CPU built from scratch. This is the full-on documentation for the VR16 CPU (which is the name for it).

VR16 runs on it's own <span class="cb">instruction set</span> called <span class="cb">VR16-ISA</span>. At the moment, this is at version alpha.

This is not a RISC-V CPU, but a RISC one.

GitHub repository: [Link](https://github.com/bsod2528/cpu)
{:.info}

NOTE: These documentation will keep changing, the proper <span class="cb">STABLE</span> release will be showcased, this is just the <span class="cb">TESTING</span>
version for now.
{:.warning}

# Specifications
The following mention the specifications of VR16:
- single-stage, multi-cycle cpu
- 16-bit cpu (this is the 2nd time I've mentioned that lol)
- has 4 general purpose registers
- supports <span class="cb">immediate values</span>
- basic branching of 1 command supported

# Setup
On how to run this project in your local machine. 

## Windows
1. Install WSL and install `gtkwave` and `iverilog`.
2. Setup venv in root directory. 
3. Run `./compile.sh` and then `./sim.sh` to view the rtl waveforms.

## Linux
1. Install `gtkwave` and `iverilog`.
2. Setup venv in root directory.
3. Run `./compile.sh` and then `./sim.sh` to view the rtl waveforms.
